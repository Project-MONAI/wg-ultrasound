# Datasets

`DATASET_ROOTS` in each script expects a local folder per dataset, named as below, all inside a shared `Datasets/` directory:

```
Datasets/
├── AIIMS/
├── Aliza/
├── Breast_Lesions_USG/
├── Heartcycle/
├── ReMIND/
├── TCIA_IDC_Prostate_MRI_US_Biopsy/
├── UTA4/
├── UTA7/
└── UTA10/
```

For source/repository links, anatomy, mode (2D/3D/4D), raw-DICOM availability, vendor(s), access type, and notes on value/limitations for each dataset, see the master tracker:
